# 场景套件与尺规（Scene Kit）

本轮把「三套主题房间 + 稀疏道具」升级为**一套以米为单位的场景套件**：10 个关卡各自拥有独立的生物群系、近中远景层次和工业级配景。此文档是尺寸、结构、预算和验收的唯一依据。

## 1. 尺规契约

**1 个世界单位 = 1 米。** 所有道具、建筑、地形的尺寸都来自 `src/render/scene/units.ts`，不按「看起来差不多」缩放。

主角车（来自 `vehicle.ts` 的车身站位）：长 **4.65 m**、宽 **2.13 m**、高 **1.16 m**、轴距 3.10 m、轮胎直径 0.79 m。

## 2. 结构

```
src/render/scene/
├── units.ts        // 公制契约 + 比例不变量 + 障碍物尺寸表
├── registry.ts     // 几何/材质/贴图生命周期（换关即释放）
├── kit.ts          // 分块实例化搭建器（block/panel/beam/column/torus/…）
├── materials.ts    // 共享 PBR 材质 + 程序化贴图（瓦楞、箱体贴图、幕墙、警示纹）
├── textures.ts     // 文本标牌工厂（缓存同文案材质）
├── props/          // 约 40 个道具/建筑构造器
│   ├── civic.ts    // 仓库、机库、塔台、筒仓、油罐、水塔、灯塔、岸桥、龙门吊、船舶、门架
│   ├── cargo.ts    // 集装箱、托盘、油桶、轮胎堆、叉车、正面吊、警示拖车、勤务皮卡
│   ├── hardware.ts // 护栏、防撞墩、轮廓标、锥桶、路灯、电杆、输电塔、风机、测风塔
│   ├── nature.ts   // 针叶/阔叶/灌木/草丛/巨石/岩柱
│   └── mega.ts     // 塔吊、发射塔、雷达、系泊桅杆、桥墩、浮标、工作船
└── biomes/         // 10 套场景编排 + 分场景大气预设
```

**层次契约**（侧视镜头下的可见性）：

| 距离带 | Z 范围（相对车道中心） | 允许内容 |
|---|---|---|
| 近景 | 0 ~ 26 m | 护栏、锥桶、轮廓标、路灯底座、岗亭、低矮货堆（≤4 m） |
| 中景 | 30 ~ 65 m | 仓库、机库、办公楼、塔台、油罐、集装箱堆场 |
| 远景 | 70 ~ 170 m | 岸桥、发射塔、摩天楼、桅杆、输电塔、风机 |
| 天际 | 180 ~ 450 m | 雾化山脊、岛链、云层（不投射阴影、无贴图采样） |

高物体只能在中景以外；近景带任何高于 4 m 的物体都会遮挡赛车，属于越界。

## 4. 性能预算

- **实例化 + 分块**：同几何同材质同 140 m 区块合并为 1 个 `InstancedMesh`，视锥与阴影裁剪按区块生效。
- **阴影**：仅 `near` 细节投射阴影；远景不投影。
- **地形 LOD**：山脊分 `near/mid/far` 三档网格（步长 1.45 / 2.8 / 6.5 m），远景改用无贴图纯色雾化材质。
- **道具 LOD**：集装箱在 `near` 才建锁杆、门框、上下导轨；远景只留箱体与角柱。
- **实测**（1440×900，headless Chromium，含阴影 pass）：10 关 **145–195 draw call / 33–45 万三角形 / 40–60 FPS**；相比改造前的 20–30 万三角形，多出的部分用于可见的近中景配景，且逐关可通过 `window.__ROADSTER__.budget()` 审计。

## 5. 素材与许可

- 建筑、道具、地形全部**运行时生成**（`BufferGeometry` + 共享材质），零下载、零额外网络体积，便于静态部署。
- 贴图仅使用仓库内已有的 3 套 **CC0** 扫描（Poly Haven：`concrete_floor_02`、`rock_face_03`、`coast_sand_01`，见 `public/textures/environment/provenance.json`）。
- 瓦楞钢板、集装箱涂装、幕墙、警示斜纹、标牌文字均由 Canvas 程序化生成，缓存后按内容复用。
- 不引入第三方建筑模型，避免风格不一致、体积膨胀与授权风险；车辆仍为原创模型。

## 6. 验收

- `tests/scale.test.ts`：8 项，覆盖公制比例、ISO 箱体、道路/护栏/建筑/隧道/港机/风机的比例关系，以及 10 关生物群系唯一性。
- `tests/scale.test.ts` 属于 `npm test`（共 126 项全部通过）。
- `tests/capture/capture-scenes.mjs`：逐关驾驶并截图 + 输出 draw call / 三角形统计，用于视觉回归。
- 视觉核验目录：`artifacts/scene-suite/`。

## 7. 已知边界

- 侧视跟随镜头决定了**完全封闭的隧道不可用**（近侧墙会挡住赛车），因此 7 关采用真实存在的「明洞／岩石廊道」断面：山侧衬砌 + 悬挑顶板 + 山谷侧立柱。
- 场景只影响渲染，不改变物理、路线、检查点或驾驶数值。
- 7 关的明洞随路线高度逐段抬升；当赛车处在高差较大的恢复平台时，镜头可能短暂高于该段顶板，从外侧俯视廊道。遮光与雾仍保持黑场，但这不是完全封闭的观感。
- `tests/browser/environment.spec.ts` 的残骸断言与 `gameplay.spec.ts` 的 `record.revision===3` 断言在本轮之前就已与当前关卡数据不一致（关卡修订号已为 4；残骸节点层级已合并），属既有测试漂移，本轮未改动其行为。
