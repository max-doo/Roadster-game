# 已知限制与待验证事项

截至 2026-10-18，扩展后的三关、收集、动态平台、完整菜单流程、持久化、声音和静态构建已在本机 Chromium 浏览器执行验证，详见 [玩法扩展验收记录](gameplay-expansion-acceptance.md)。以下事项不应被描述为已经通过真实设备或商业发行验收。

## 尚未充分验证

1. **真实移动设备性能与触感。** 已测试 Chromium 移动横屏视口、独立多点触摸事件和 Windows WebKit 引擎；没有连接真实 iPhone、iPad 或 Android 手机。刘海安全区、动态地址栏、系统手势、热降频、长时间续航及双拇指舒适度需要设备验证。较新设备 60 FPS、中端设备 45 FPS 是目标，不能由桌面模拟成绩推定。
2. **Safari 实机兼容性。** 历史版本的 Windows WebKit 27.2 已加载当时的生产构建并完成三关输入重放；本轮新增移动机关尚未重新执行 WebKit 验证。它不等同于已验证 iOS Safari 的 WebGL、触摸、音频与全屏策略。没有全屏 API 的浏览器保留正常网页玩法；横屏提示可关闭。
3. **主观声音混音。** 浏览器测试验证 AudioContext 激活、轮胎接触、制动、喷气、暂停及静音节点的实时变化。没有把这些断言当作耳机听感、移动扬声器响度或无听觉疲劳的验收证明。视频录制不含音轨。
4. **长时间稳定性。** 场景切换检查未发现 GPU 几何体或纹理持续增长；这不是数小时运行、后台恢复、设备内存压力和反复上下文丢失的耐久测试。

## 已说明的设计边界

- 车辆为基于 2026 年 10 月外观照片制作的原创游戏模型，具有约 10.76 万三角形和完整底部机械层次。它不是官方 CAD，也不是经过尺寸测量的工程复刻。风扇、喷嘴内部、悬架和部分翼面机构是游戏美术解释，来源和授权边界见 `asset-manifest.md`。
- 游戏采用真实动态刚体的二维物理与完整三维渲染。轨道以实际深度车道分离，车辆碰撞按车道筛选；同一车道的旧路面保持实体。平移和俯仰仍由 Rapier 2D 求解，深度属于预先设计的车道，不支持自由横向驾驶或任意三维碰撞。
- 长跳与高空释放会扩大构图以同时呈现车辆和后续落地平台，横屏小屏幕上车辆因此变小。已检查模拟视口中的可见性；真实小屏幕辨认姿态的舒适度仍需设备体验。
- 所有动力、气压和吸附数值为游戏调校值，不代表真实车辆性能。辅助阻尼与轻微着陆辅助有明确上限，缺少推进、吸附或主动姿态操作时对应挑战无法完成。
- 运行时车模由源码生成，导出的 `assets/roadster-2026.glb` 是可编辑交付资产，不重复加载到生产包。当前场景主要以材质合批、实例化、粒子池、像素比和阴影调节控制成本；低画质仍保留车身关键外形。
- 生产构建存在 Three.js 与 Rapier WASM 分块超过 500 KB 的体积提示，没有隐藏此提示。实际构建、资源请求和本地加载已验证；弱网首访加载时间仍需真实网络测试。

## 商业发布边界

本项目没有 Tesla 工业设计或商标商业使用许可。运行时不包含参考照片、官方标志、官方视频音轨或来源不明的模型。原创几何和合成声音的来源明确，但不能由此推定车辆造型的商业授权。公开商业发行前仍需单独处理该许可问题；当前成果定位为独立同人 MVP。
