# 物理实现与调校

`src/game/core.ts` 使用 Rapier 2D 动态刚体处理车辆平移、俯仰、惯性与碰撞。应用以 1/120 秒固定步长调用物理，渲染采用独立帧率；配置集中在 `src/game/config.ts`。米、秒、千克作为内部单位，HUD 将速度换算为 km/h。

## 悬架与驱动

车身质量为游戏单位 1，转动惯量 3.6；前后轮轴分别位于中心前后 1.55 米、向下 0.25 米。每个轮轴在共享赛道线段上寻找最近有效接触，依据距离和接触点速度施加弹簧、阻尼力。力作用于对应轮轴位置，因此会产生真实俯仰力矩。车轮不各自创建刚体，减少移动浏览器的约束求解成本。

赛道点列定义实际可行驶表面，法线为前进切线的左法线；对应厚度 0.44 米的 Rapier 静态甲板位于表面背后。加速和制动力沿接触切线施加，速度接近上限时驱动力逐渐降低；倒车复用同一条曲线，后退极速与前进一致，只是从前进中制动时先使用更强的制动力。空气阻力随速度平方增加。普通平地车身中心稳定在路面上方约 0.84 米。

环形轨道采用带深度坐标的螺旋连接。第二关入口与出口相隔 8 米，甲板宽 4.5 米，实际三维几何不再共面重叠。第三关也用不同深度车道分离上层入口与下层接收平台。Rapier 继续计算平面刚体运动，深度由当前轨道车道确定；碰撞仅过滤不属于车辆所在车道的甲板，同一车道上已经经过的道路仍保持实体。因此从高处掉落时可以碰到下方真实存在的道路。第二关另有宽恢复平台，稳定接收掉落车辆并连接接收道路。恢复路段不增加主路线的进度分母。

## 吸附

玩家按住吸附且未按住喷气、轮轴接近有效特殊表面时，额外力沿轨道负法线作用，将车辆拉向甲板。该力与悬架反作用、重力及圆周运动的惯性共同决定能否保持接触。范围之外不产生远程吸引；按住按钮也不会自动把车辆贴回赛道。

世界重力恒为 `(0, -18)`。倒立行驶时，轨道法线向下，风扇力向上抵抗重力。关闭风扇后刚体自然离开天花板并下落。有限的切线对齐力矩帮助悬架跟随曲率；姿态仍由刚体求解，不直接设置旋转。

## 推进与姿态

喷气合力由车身前向的 13 和车身上向的 26 两个加速度分量组成。 对应的排气方向分别是车身后向和车身下向，渲染分开从后部与底部喷口发射，并随车辆姿态旋转；倒立时底部气流在世界坐标中朝上，反作用力朝下。喷口布局是游戏模型参数，非官方尺寸。持续使用每秒消耗 23 点压力；最后一帧按剩余压力缩放推力，压力归零后停止。松开喷气后保留当前速度并继续受到重力和阻力影响。

空中姿态输入施加正负力矩。无输入时通过角速度阻尼抑制持续旋转；接近落地表面时有有限姿态辅助。Skyfall 的倒立释放无法仅靠该辅助自动转正，玩家需要完成约半圈主动旋转，再按正确姿态使用喷气缓冲下降。

## 失败与完成

车辆初始生命值为 100。车轮重新接触时根据落地法向速度与姿态误差计算损伤；车身实体碰撞则依据刚体求解前后的冲量变化估算冲击，危险结构还检测接触进入。一次撞击有 0.7 秒损伤冷却，避免同一次接触被连续计费。普通撞击和重落地先扣血，生命耗尽或跌出关卡边界才失败。翻覆落在路面上时进入独立翻覆状态；低速、车身接触、车轮未支撑且车身偏离正常上向时，姿态扭矩提高到 65，使玩家能够翻正。没有有效位移或转角进展达 6 秒才判定受困失败；正常倒立吸附有有效车轮支撑，不计入受困。

复活时把检查点位置投影到指定实际轨道，依据切线重建角度、依据法线留出悬架间距，并恢复正确车道、满血、预设气压与零速度。有效吸附表面提供独立的复活静止保护，首次驾驶输入时结束；不向输入层写入锁定吸附状态。另有短暂伤害保护。所有检查点都测试复活后无操作静置两秒，包括倒立检查点。

完成判定同时要求依次激活所有检查点、到达终点范围以及车轮有效接触。运行期车身平面位置与角度的直接重置仅发生在检查点重试中；输入重放通过普通操控到达终点。

## 验证范围

Vitest 覆盖正常驾驶、制动与倒车、喷气压力耗尽、空中姿态方向、无输入不通关、三关完整重放、缺少关键能力时失败、吸附关闭后下落、普通和倒立检查点恢复，以及 30 / 60 / 144 Hz 渲染下固定物理累积器的一致性。真实车辆参数、轮胎接触斑、复杂三维翻滚和物理设备体验不在此简化模型的验证范围内。

喷气输入在物理核心中也优先于吸附，避免开发重放或其他输入通道绕过互斥规则。只要喷气按钮仍按住，吸附力就是零；释放喷气后才根据当前吸附输入恢复。气压耗尽不会自行启动吸附。

空中主动俯仰增加对应气流：正向俯仰使用前部向下与后部向上的排气，负向俯仰反过来，两组视觉反作用方向形成力偶，合力为零、力矩符号与当前控制一致。方向随车身旋转并继承刚体线速度和角速度。气流强度随输入幅度变化；松手、接地、失败或完成时停止发射。此项将既有俯仰扭矩可视化，没有改变物理调校或增加姿态控制的压力消耗。

翻覆识别使用接触、车轮支撑、速度与朝向共同判定，避免把正常向上的路障碰撞误认成翻覆。受困窗口在明显平移超过 1.5 米或转角变化超过 0.65 弧度时重置，恢复正常支撑／离开车身接触也清除。暂停不推进计时，检查点重试清除提示与计时。气流和声音允许在翻覆恢复时继续响应姿态输入；翻覆接触不计入空中时间。
