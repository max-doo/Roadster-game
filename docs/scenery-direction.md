# 场景视觉方向

本轮延续既有的航天汽车试验场风格，重点是让玩家能够从画面判断物体的尺度、材质和空间关系。车辆、可行驶路面、障碍边界和落点必须先于背景细节被识别。

## Direction contract

**用途与构图。** 游戏画面属于 Experience：玩家关注驾驶与飞行。沿用现有跟随镜头、三关路线和操作界面，让近处路障轮廓清晰、中景设施提供尺度、远景负责气氛。

**材质。** 近处混凝土使用实拍扫描的颜色、法线和粗糙度贴图；岩壁和沙地使用不同扫描材质。金属靠倒角、面板、接缝和反射表达结构，避免把所有表面处理成同一种噪点。

**障碍。** 事故车辆具有连续的车身轮廓、独立车窗和轮拱；货运设施保留框架、锁杆和标识。危险条纹使用表面贴图，限制在实际面板内。所有移动部件跟随已有物理时钟。

**背景。** 远景采用天空全景、低成本三维山体和空气透视；中景继续使用模块建筑，但降低重复构架的视觉密度。天空跟随镜头平移，保留地形的真实视差。

**实现边界。** 保持三维渲染与二维物理分离，不调整路线、碰撞和驾驶数值。重复零件合批，以实际浏览器统计评估成本；本轮不引入新渲染引擎、后处理框架或资产管理系统。

**验收。** 使用相同重放位置对照三关桌面与手机横屏截图，检查材质、轮廓、空间层次、落点可见性与移动门同步。记录页面错误、请求失败和绘制调用。模拟手机结果不代表真实手机性能。
