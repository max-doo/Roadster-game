# FAULTLINE 实现与验收

## 当前可玩内容

游戏已包含 01–10 共十关。第二篇章的七关均有起点、完整道路、机关、固定检查点、气压补给、四枚可选挑战星、终点和结算，第三关完成后依次解锁。十关共用现有车辆操作，关内不增加按钮。

下表的长度是关卡文件中的路线预算，包含回环、倒置和跨越段，合计约 10,020 米。固定恢复区会根据实际几何保留安全长度，因此预算不等于终点横坐标，也不是逐帧测得的车辆里程。

## 代码维护

每关的名称、环境、教学与阶段顺序在 `src/game/levels/04-aftershock.ts` 至 `10-terminus.ts` 独立维护。`faultline.ts` 将阶段配置构造成既有 `Level` 和 `Track` 数据，`index.ts` 明确指定十关的加载顺序。道路点位同时供物理和渲染使用。

维护单关时优先调整对应编号文件的阶段类型、长度、宽度、星星和教学。调整一种机关的几何实现时修改 `faultline.ts` 对应分支，并重放使用该机关的关卡。车辆力学参数仍集中在 `config.ts`，不在关卡中覆盖。

## 机关的实际规则

承重路板长约 15 米，相邻板之间留 1 米断口，每组六块。车辆轮胎首次接触后启动坍塌计时：04 首段为 0.9 秒、后段为 0.75 秒；终局复习段仍为 1.4 秒；预警时抖动并显示 HUD 提示，计时结束后同时关闭实体碰撞与悬架采样。可见路板继续按物理时钟向下坠落，随后隐藏。检查点保存已触发路板的时间，重试恢复同一状态，起点重试则恢复全部路板。

04 中段两块震荡桥板各长 22 米、垂直行程 6 米，周期分别为 7 秒和 8 秒，并使用不同相位。玩家需要在低位驶入、高位驶出，中间固定安全岛允许制动和观察。服务飞跨断口为 28 米，终点断口为 36 米。第四关路线 revision 为 3，原版本成绩按现有规则归档，解锁进度保留。

横移平台的板面长 26 米，横移 24 米，周期 9 秒；升降托架的板面长 22 米，升程 6 米，周期 10 秒。两端停靠阶段均占周期的四分之一。碰撞体、悬架速度、可见平台和平台上的星星使用同一运动时钟。所有检查点均在固定表面。

07 和终局暗区的灯控闸在车头朝向闸门、距离小于 25 米时启动。先等待 0.8 秒，再用 1.2 秒升起面板；启动状态随检查点恢复。其他升降闸保留确定性的周期运动。车灯自动工作，道路边缘与危险物保留可见标记。

风区由矩形范围、边缘渐变距离、水平和垂直力、可选周期组成。当前水平力使用正负 7，垂直力最高为 7，采样函数将水平绝对值限制在 8 以内。风力施加到车辆质心，不添加扭矩；阵风用平滑周期函数改变方向。暂停时风、平台和坍塌计时一起停止，重试回到检查点时钟。

09 的固定换轨段使用上下交替的四段窄轨和短缺口，后续倒置长廊需要反向行驶。它与 05 单向爬升、托架随行和天花板释放的操作节奏不同。07 下层检修路在独立深度车道爬升，到达上层路面高度后再合流，避免车辆撞到上层道路底部。

## 流程与存档

菜单与存档上限读取 `LEVELS.length`。关卡列表可滚动到第十关，文件和界面的序号统一使用两位数字，支持中文名称和前置关卡解锁提示。列表、HUD 和结算从各关收集物计算星星总数；通关奖牌仍是三个等级。

原三关的 ID 和路线 revision 不变，新七关使用各自独立记录。旧成绩、已收集星星、设置和已解锁进度继续读取。第十关显示“试验计划完成”，返回车库，不进入不存在的第十一关。

场景继续复用现有工业环境和资产，并加入海面、塔架、港口龙门、风机与锚塔轮廓。四首已有本地配乐分配到新增关卡，不增加外部运行时依赖。

## 验证入口

```powershell
npm test
npm run build
npx playwright test tests/browser/faultline.spec.ts tests/browser/gameplay.spec.ts tests/browser/game.spec.ts tests/browser/environment.spec.ts
node tests/acceptance/production-faultline.mjs
```

生产冒烟检查要求先在 4173 端口启动构建预览。旧关卡截图目录被其他进程占用时，可将 `ROADSTER_GAMEPLAY_CAPTURE_ROOT` 指向独立输出目录后重跑对应浏览器用例。

`tests/faultline.test.ts` 覆盖七关无可选补给通关、重试后继续通关、七关四星收集、07 下层检修路线、坍塌碰撞与悬架同步失效、风力确定性与无额外扭矩、灯控闸恢复、旧记录保留和十关解锁。既有物理测试另行覆盖十关所有检查点的静置安全。

`tests/browser/faultline.spec.ts` 在真实 Chromium 的桌面 1440×900 与模拟手机横屏 780×360 下，各重放七关全收集通关，检查结算、十关列表、旧记录和刷新后的保存结果。重放仅调用正常加速、制动、吸附、喷气和姿态输入，不写车辆位置、生命、气压、检查点或完成状态。

画面、完整快照和浏览器指标保存在 `artifacts/faultline/`。截图在停止推进物理后给镜头留出收敛时间；这些画面用于检查实际渲染，不作为持续帧率测量。

## 验收边界

自动输入重放证明路线、收集和恢复流程可执行；它不等同于真人首次游玩的时长与手感评估。策划中的首通时间、奖牌阈值和初版坐标还需要结合真人试玩继续调校。真实手机、iOS Safari、长期运行和稳定 GPU 性能尚未验收；场景的远地形复用也保留原有美术限制。

本轮生成当前十关的 `dist/`，旧的三关发行 ZIP 和旧发布清单没有重新打包。开发前工作区修改已提交为 `2986112`；本轮新增开发文件和验收材料保留在工作区供审阅。
