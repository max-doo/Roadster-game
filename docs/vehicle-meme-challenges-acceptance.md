# 交通事件与场景优化验收

日期：2026-10-19。对应当前优化后的路线，旧版本的三秒预告与高台避让验收不再适用。

## 已实现

全部 35 段事件保留；移除事件专用安全桥和吸附旁路。电池释放提前至 0.42–0.72 秒、后飞速度提高到 24–32 米／秒，后车从更近处高速接近；占道车与静态车障使用下载的 CC0 厢式货车，碰撞尺寸同步调整。驾驶 HUD 不再显示关卡名称、路段名称、事件方向或解法文字，也不提前播放事件提示音。场景说明牌文本移除；检查点保留“检查点＋编号”的独立牌面，移除立杆和横梁，HUD 同时显示进度，不弹出遮挡对白的居中浮窗。电池前车保持原有发射位置，发射前可见，发射后停留；两类车辆使用发生时的车顶玩梗对白。

原有景深 S 弯改为实际道路高度的变化，波浪坡、连续起伏和凹谷参与驾驶物理；五个后期关卡加入 80–88 米的长陡坡，部分坡道需要贴地喷气。扩大普通断桥、阶梯、换轨和倒置断口，同时保留合理的落地缓冲。仍采用原有 2.5D 操作。

货车始终固定在原位，进入事件前可见，通过后仍保留实体，按关卡和车次更换配色。SUV 已自行重建细化，增加独立车窗、门缝、轮拱、胎块、轮毂、刹车盘、雨刷及灯具；约 2.8 万三角面，按材质合并绘制。

新增 Shift／触屏“喷气加速”，只在接触道路时施加沿路面的推力，不启动升力喷口，腾空后停止耗气。气量按单位显示，初始 100、气瓶增加 40，可累积超过 100，无容量上限。经过检查点不再补气；重试恢复当时储量和匹配的气瓶状态，不能通过重试刷气。04–10 检查点数为 4／4／4／3／4／4／4。

电池车和后车已按 iCAR 03／03T SUV 与尊界 V800 MPV 的车身类型改为原创参考外观。精确车型的免费模型尚未落实，不能将这部分算作“已下载并完成车型替换”。货车来源、授权和原始哈希见 public/models/traffic/source.json，检索过程与限制见 [模型核验记录](traffic-model-research.md)。

## 验收边界

本轮证明关卡可通、资源加载正常、提示已移除及修订后的事件需要正确操作。自动重放知道道路和车辆状态，不能证明首次真人游玩的体感难度达标；仍需要真人试玩调节节奏。未做真实手机性能、iOS Safari、长时间 GPU 或发行 ZIP 验收。旧发行 ZIP 没有更新。
